# Données
* Valeur mesurée : $f = \qty{145}{\mega\hertz}$
* Précision : $\qty{10}{\ppm}$

# Méthode
$\unit{ppm}$ signifie *parts per million* (parties par million) : $\qty{10}{\ppm}$ veut donc dire $10$ pour $10^6$.  

$\Delta f = \qty{145}{\mega\hertz} \cdot \frac{10}{10^6} = 145\cdot \cancel{10^6}\unit{\hertz}\cdot\frac{10}{\cancel{10^6}} = \qty{1450}{\hertz}$

$f_\text{min} = f - \Delta f = \qty{145}{\mega\hertz} - \qty{1450}{\hertz} = \qty{144,99855}{\mega\hertz}$
$f_\text{max} = f + \Delta f = \qty{145}{\mega\hertz} + \qty{1450}{\hertz} = \qty{145,00145}{\mega\hertz}$
