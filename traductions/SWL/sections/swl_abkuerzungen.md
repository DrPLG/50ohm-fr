Le radioamateurisme emploie de nombreuses abréviations comprises dans le monde entier. Elles font gagner du temps et aident à franchir les barrières de langue.

<margin>
| l: Abréviation | X: Signification                                        |
| CQ           | appel général ; toute station peut répondre             |
| CW           | Continuous Wave, la télégraphie Morse                   |
| DX           | grande distance, ou station très éloignée               |
| RX           | récepteur                                               |
| TX           | émetteur                                                |
| TRX          | transceiver, c'est-à-dire émetteur-récepteur            |
[table:swl_abkuerzungen_uebersicht:Abréviations d'exploitation au programme de l'examen]
</margin>

Un appel tel que *CQ CQ CQ de DL1ABC* ne s'adresse pas à une station déterminée : c'est un appel général. Le *de* signifie ici *de la part de*. Pour un SWL, un appel CQ est une bonne occasion de relever tranquillement l'indicatif, puis d'attendre la station qui répondra.

Les sigles TX et TRX apparaissent aussi sur les afficheurs des appareils. Un SWL travaille en mode RX. Si l'indication TX s'allume par mégarde sur un transceiver, c'est que l'appareil est peut-être en train d'émettre.
