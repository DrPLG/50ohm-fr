Certaines phrases reviennent dans presque tous les contacts. Pour les dire vite, et pour qu'elles soient comprises dans toutes les langues, les services radio utilisent depuis plus d'un siècle des abréviations de trois lettres qui commencent toutes par Q : les *codes Q* [index:Code Q].

Un code Q peut être une affirmation ou, suivi d'un point d'interrogation, une question. « QRV » veut dire « je suis prêt » ; « QRV? » demande « êtes-vous prêt ? ».

| l: Code | X: Sens |
| QRA | le nom de ma station est… |
| QRM | je suis brouillé par d'autres émissions |
| QRN | je suis gêné par des parasites naturels, les orages par exemple |
| QRT | j'arrête d'émettre |
| QRV | je suis prêt |
| QRZ? | qui m'appelle ? |
| QSB | votre signal varie, il monte et descend |
| QSL | j'accuse réception |
| QSO | un contact entre deux stations |
| QSY | je change de fréquence |
| QTH | ma position est… |
[table:bir_codes_q:Les codes Q du BIR]

---

Les radioamateurs les emploient aussi en parlant : « mon QTH est Lyon », « je passe QRT », « on fait QSY sur une autre fréquence ». On les entend encore plus souvent en Morse, où ils font gagner beaucoup de temps.

<tip>
Pour distinguer QRM et QRN, pensez à la dernière lettre : QR*N* comme *nature*, pour les orages et les parasites naturels ; QR*M* pour ce qui vient des *machines* et des autres émetteurs.
</tip>
